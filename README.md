# 🛍️ NITO.Store

Modern, clean, and responsive **store landing page** built using pure **HTML & CSS**.  
Focused on UI/UX, smooth animations, and a minimal premium look.

🔗 **Live Demo:**  
https://sufyanito.github.io/nito-store/

---

## ✨ Features

- Clean & modern UI design
- Fully responsive layout (desktop & mobile)
- Smooth hover animations & transitions
- CSS Grid & Flexbox based layout
- Custom hero section with floating animation
- Mobile-friendly UX (no hover issues)
- Lightweight & fast (no frameworks)

---

## 🧰 Built With

- **HTML5**
- **CSS3**
  - Flexbox
  - Grid
  - Media Queries
  - Animations & Transitions
- **Google Fonts (Poppins)**

---

## 📱 Responsive Design

The layout adapts smoothly to different screen sizes:
- Desktop: full experience with animations
- Mobile: simplified UI for better usability


---

## 🚀 Deployment

This project is deployed for free using **GitHub Pages**.

To run locally:
1. Clone the repository
2. Open `index.html` in your browser
